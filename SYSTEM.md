## 2. Standar Kualitas (Anti-Slop UI)
- **NO Generic Template:** Hindari layout sejuta umat (teks kiri + 3 angka stat card kaku).
- **NO Excessive Effects:** Jangan gunakan blur orbs berlebihan, glassmorphism murahan, glow neon norak, atau animasi framer-motion yang bikin berat.
- **Modern Minimalist & Clean:** Tipografi tajam, spacing proporsional, contrast ratio nyaman di mata (WCAG AAA), mobile-first.

## 3. Tech Stack Utama
- **Framework:** React.js, Next.js (App Router & Pages Router)
- **Styling:** Tailwind CSS (Modern classes, responsive prefixes)
- **State & Routing:** Zustand, React Router DOM, TanStack Query
- **Maps & Geolocation:** Leaflet, OpenStreetMap, OSRM Routing Machine
